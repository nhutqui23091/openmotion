Adapt

  • Edit headline, request and tagline in the root project variables.
  • Keep the request panel visible while the result changes; both sides share one task name.
  • Show the layout skeleton before charts and fields; keep loading and finished states in the same positions.
  • The project is silent; add narration and music as a separate audio clip if required.
